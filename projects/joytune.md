# JoyTune - AI Celebration Studio

**Personalized Songs, Cards, Greetings, and Celebration Projects**

- **Status:** Phase 1 live
- **Working name:** JoyTune is a working name, subject to trademark and domain checks before any public launch.
- **Profile:** https://github.com/SheldonMendoza

## Description

A personal celebration studio for everyday people: personalized original songs, greeting cards, daily greetings, and celebration projects, built for grandparents, parents, couples, and friends, not just creators.

## Objectives

- Let anyone create a personalized song or card for someone they love
- Keep generation honest: if a capability is not connected, the UI says so plainly
- Provide a guided Easy Mode flow, a personal library, and a credit ledger

## Technologies used

Only verified information is listed.

- Cloudflare Workers + D1 + R2
- Workers AI for lyrics and spoken-word audio in Phase 1

## Development status

Phase 1 live: brand and responsive UI, real session auth, personal library, Easy Mode, Daily Greetings Hub, AI Music Studio for lyrics and spoken-word audio, Greeting Card Studio, credit ledger, PWA support, and admin dashboard.

Sung vocal/instrumental music generation was honestly pending in Phase 1, with no free text-to-music model on Workers AI. Video is a Phase 2 placeholder.
