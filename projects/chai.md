# CHAI - Caribbean Herbal Ancestral Intelligence

**Caribbean Medicinal-Plant Knowledge Platform**

- **Status:** Phase 1 live
- **Test site:** https://chai-3yp.pages.dev
- **API:** https://chai-api.sheldonmendozaproductions.workers.dev
- **Public repository:** https://github.com/SheldonMendoza/CHAI-Caribbean-Herbal-Ancestral-Intelligence

## Description

A database-backed medicinal plant encyclopedia, with per-claim scientific evidence assessments, a traditional knowledge library, and AI research assistants in later phases.

Tagline: Where Ancestral Wisdom Meets Artificial Intelligence.

## Objectives

- Document Caribbean medicinal plants with verified identities and sources
- Separate traditional use from scientific evidence, per claim
- Provide honest evidence ratings, with unverified fields left empty, never invented

## Technologies used

Only verified information is listed.

- React 19 + TypeScript + Vite
- Cloudflare Workers + D1

## Development status

Phase 1 complete: site, design system, database schema, 15 verified starter plants, and working search. AI chat, accounts, community posting, and admin UI arrive in later phases.
