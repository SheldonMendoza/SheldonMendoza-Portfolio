# TRINIBAD

**Caribbean-Inspired Open-World Game**

- **Play the prototype:** https://muse.ai/s/trinibad-zr6xf2kxmcwxlr/w0CJz-JeN_on_6_e0khIACLUTcemwbAanvtGoOxntdM
- **Status:** Playable prototype v0.2.8, in development
- **Profile:** https://github.com/SheldonMendoza

## Description

A Caribbean-inspired open-world gaming concept influenced by GTA-style gameplay, featuring Caribbean environments, characters, culture, and interactive experiences.

The prototype is set in downtown Port of Spain, around Independence Square. It includes walking, running, jumping, a drivable yellow maxi-taxi, local characters, coins, and a TT$ HUD starting from TT$250.

## Objectives

- Create a playable Caribbean open-world game
- Represent Port of Spain environments, characters, and culture
- Build interactive gameplay around Caribbean everyday life
