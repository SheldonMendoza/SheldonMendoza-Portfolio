# CSIA Academy - Caribbean Super Intelligence Academy

**Caribbean Education Technology Platform**

- **Status:** Infrastructure foundation live. Application not yet built.
- **Profile:** https://github.com/SheldonMendoza

## Description

A Caribbean-centered educational technology platform covering Caribbean culture, creativity and the creative industries, artificial intelligence, technology, digital creation, AI education, and entrepreneurship, with interactive learning: courses, lessons, quizzes, projects, certificates, AI-powered tutoring, and educational tools.

## Objectives

- Build a Caribbean-first learning platform for culture, creativity, and AI
- Provide courses, projects, and certificates
- Add AI-powered tutoring and educational tools in the application build

## Technologies used

Only verified information is listed.

- Cloudflare Workers + D1 + R2
- React SPA served as static assets

## Development status

Infrastructure foundation only. The repository contains the complete GitHub + Cloudflare development infrastructure, build pipeline, hosting, database, storage, and documentation. There are no courses, no user accounts, and no AI features yet, only a pipeline validation page.
